# ToneForge Pocket

Version iPhone (PWA Safari) de ToneForge : NAM en WebAssembly dans un AudioWorklet, IR/EQ/delay en nœuds Web Audio natifs. Même hébergement que Dial In (GitHub Pages).

Prototype 1 (`index.html`) : passe-son clean/drive + mesure de latence aller-retour (câble sortie → entrée 1).
Matériel : iPhone USB-C + carte USB IV.
